化学反応と化学式

反応は原子の組み替え。だから両辺で原子の数を合わせる

更新: 2026-07-07

鉄が錆び、木が燃え、電池が電気を生む。見た目はまるで違うのに、化学反応で起きていることは全部同じ——原子が組み替わる だけだ。原子そのものは新しく生まれも消えもせず、ただ 結合する相手が変わる。この一点さえ押さえれば、化学式の「係数合わせ」がなぜ必要なのかが最後までつながる。

反応は原子の組み替え

水素が燃えて水になるとき、水素原子と酸素原子が消えて水が湧いて出るわけではない。もともとあった H と O が、くっつく相手を変えて並び直しただけだ。

  • 反応物 反応する前の物質。化学反応式では左辺（矢印の左）に書く。 （左辺）にある原子と、 生成物 反応してできた物質。化学反応式では右辺（矢印の右）に書く。 （右辺）にある原子は、種類も個数も同じ
  • 変わったのは「どの原子がどの原子と結びついているか」＝結合の相手だけ

だから反応の前後で全体の重さは変わらない。これが 質量保存の法則 化学反応の前後で、物質全体の質量は変化しないという法則。原子が消えたり生まれたりしないことの現れ。 で、反応式を書くときの土台になる。

化学式でどう書くか

反応を記号で表したものが 化学反応式 反応物と生成物を化学式で書き、矢印でつないだ式。両辺で各元素の原子数が一致していなければならない。 。反応物を左、生成物を右に置き、矢印 → でつなぐ。

ただし記号を並べただけでは足りない。原子は消えないのだから、左辺と右辺で各元素の原子数がぴったり同じ でなければならない。そこで分子の前に 係数 化学式の前につける数。その分子が何個あるかを表す。両辺の原子数を合わせるために調整する。1のときは省略する。 という整数を付けて、個数を釣り合わせる。この作業が「バランスを取る」。

例として水の生成を見る。まず素直に書くと、右辺の H₂O には O が1個しかなく、左辺の O₂（2個）と合わない。

段階式H（左 / 右）O（左 / 右）判定
書いただけH₂ + O₂ → H₂O2 / 22 / 1O が不足
H₂O を2倍H₂ + O₂ → 2H₂O2 / 42 / 2今度は H が不足
H₂ も2倍2H₂ + O₂ → 2H₂O4 / 42 / 2成立

ポイントは、係数はいじってよいが、化学式そのもの（下付きの数字）は変えてはいけない こと。H₂O を勝手に H₂O₂ にしたら別の物質（過酸化水素）になってしまう。個数の調整はあくまで分子の「数」＝係数で行う。

反応の代表的な型

無数にある反応も、いくつかの型に分けて眺めると見通しがよい。

型何が起きる例
化合複数の物質が1つに結びつく2H₂ + O₂ → 2H₂O
分解1つの物質が複数に分かれる2H₂O → 2H₂ + O₂
燃焼物質が酸素と激しく結びつき熱・光を出すCH₄ + 2O₂ → CO₂ + 2H₂O
中和酸と塩基が反応し塩と水ができるHCl + NaOH → NaCl + H₂O

型が違っても、やることは共通——両辺で原子数を合わせる。どの型でも係数合わせの手順は同じだ。

まとめ

  • 反応は原子の 組み替え。原子は生まれも消えもせず、結合の相手が変わるだけ（質量保存の法則）
  • だから反応式は、両辺で 各元素の原子数が一致 するよう 係数 化学式の前につける数。両辺の原子数を合わせるために調整する。 で釣り合わせる
  • 化学式（下付き数字）は物質の正体そのものなので変えない。調整するのは係数だけ
